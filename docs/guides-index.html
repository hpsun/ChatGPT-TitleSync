Coverage and remaining acceptance

Guides cover requirements, build or interpreter invocation, run/stop/restore, 45 icon use and the current three-layer policy. Per-branch timer/worker limitations are stated in its guide. Foreground default: 2 seconds fresh source; native background repair: 1 second; background source default: 5 seconds per window. A one-second schedule is not a one-second cold UIA deadline.

The support matrix records actual verification scope. See local validation and remaining release work. Current source tests and packaged smoke checks are distinct. The v0.1.0 preview is already public, while name replacement remains a feature branch without a new Release. The current Windows shared Unicode companion passed 31/31 format-CLI cases; full new desktop retesting of the eight independent Windows frontend implementations is pending. At CI 19cec808 and CI 97858710, the Foundation helper and new Swift/Objective-C clients compiled and the same 30 shared CLI cases passed; Go/Rust were still older baseline adapters. Latest AppleScript/helper boundaries, client recovery and new Go/Rust integration await the next complete CI. All Mac routes remain Experimental for real AX, menu, editor and login acceptance. Earlier static-only freezes and real-window samples are historical, not current acceptance.

Normal restoration protects external custom captions. Windows caption labels do not change taskbar application grouping; macOS titles do not rename the Dock application. Private evidence and source-title caches stay outside the source package.
